- 🔌 **API testing:** Playwright request context, JSON schema validation, bearer/OAuth authentication, CRUD and contract tests
- 🗄️ **Data testing:** SQL validation, reconciliation, ETL / data warehouse testing (Azure Data Factory, Snowflake, Power BI)
- 🔄 **CI/CD:** Jenkins, GitHub Actions, Docker, Azure DevOps
- 🤖 **AI-assisted testing:** I use GitHub Copilot, Claude Code and Playwright MCP to speed up test creation. I design the framework and the tests, and review, debug and maintain the code they produce.
